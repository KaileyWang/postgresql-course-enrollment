# 接口设计文档（API Contract）

> 版本 v0.1 ｜ 配套：`01_技术设计文档.md` ｜ 前端 `src/api/*` 必须与本文件逐字对齐
> 本文档是五人协作的**契约**，任何接口变更先改本文档并走 PR（见 04 文档）。

---

## 1. 通用约定

- **Base URL**：`/api/v1`
- **格式**：请求/响应均 `application/json; charset=utf-8`；导出接口例外（`text/csv`）
- **认证**：除 `POST /auth/login` 外，全部接口要求 `Authorization: Bearer <JWT>`，JWT 载荷含 `sub`(user id)、`role`、`exp`（默认 12h）
- **分页**：查询参数 `page`（从 1 起）、`size`（默认 20，上限 100）；响应统一分页信封：

```json
{ "items": [ ... ], "total": 137, "page": 1, "size": 20 }
```

- **时间**：全部 ISO 8601（`2026-11-19T10:30:00+08:00`）
- **金额类无**；节次为整数 1–12
- **幂等**：退课接口天然幂等（重复调用第二次返回 404）

## 2. 统一错误体

所有 4xx/5xx：

```json
{
  "error": {
    "code": "SECTION_FULL",
    "message": "该教学班已满，可选择加入候选队列",
    "details": { "section_id": 12, "capacity": 60 }
  }
}
```

### 错误码表

| HTTP | code | 触发场景 |
|---|---|---|
| 400 | `VALIDATION_ERROR` | 参数缺失/格式错误（附 `details.fields`） |
| 401 | `UNAUTHORIZED` | 未带 token / token 过期 |
| 403 | `FORBIDDEN` | 角色不足（如学生调管理接口） |
| 404 | `NOT_FOUND` | 资源不存在 / 非本人资源 / 已退课 |
| 409 | `TIME_CONFLICT` | 与已选课程时间冲突（`details.conflicts` 为冲突段列表） |
| 409 | `ALREADY_ENROLLED` | 同一教学班已有有效记录 |
| 409 | `OPTIMISTIC_CONFLICT` | V2 重试耗尽（仅教学演示出现） |
| 409 | `DUPLICATE_RESOURCE` | 管理端创建重复课程号/教学班 |
| 423 | `SELECTION_CLOSED` | 不在选课开放阶段 |
| 429 | `RATE_LIMITED` | 触发限流（学生 5 req/s） |
| 500 | `INTERNAL_ERROR` | 未捕获异常 |
| 503 | `DB_UNAVAILABLE` | 数据库不可用 |

### 选课语义（重要）

`POST /enrollments` 有三种**成功**形态，前端必须分别处理：

| HTTP | 含义 | 响应体含 |
|---|---|---|
| 201 | 选课成功 | `enrollment` 对象 |
| 202 | 满员且接受候选，已入队 | `waitlist` 对象（含 `position`） |
| 409 `SECTION_FULL` | 满员且不接受候选 | 空 details |

## 5. 详细接口

### 5.1 认证

#### A1 POST /auth/login

请求：

```json
{ "student_no": "S0001", "password": "Passw0rd!" }
```

响应 200：

```json
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer",
  "expires_in": 43200,
  "user": { "id": 1, "student_no": "S0001", "name": "张三", "role": "student" }
}
```

错误：401 `UNAUTHORIZED`（账号或密码错误）；429（同 IP 5 次/分钟）。

#### A2 GET /auth/me

响应 200：`{ "id":1, "student_no":"S0001", "name":"张三", "role":"student", "major":"计算机" }`

---

### 5.2 浏览

#### B1 GET /sections

查询参数：

| 参数 | 类型 | 说明 |
|---|---|---|
| `term` | string | 必填，如 `2026-FALL` |
| `dept_id` | int | 可选 |
| `keyword` | string | 课程名/课程号模糊匹配 |
| `only_open` | bool | 默认 false，只看有剩余名额 |
| `page`,`size` | int | 分页 |

响应 200（示例一条）：

```json
{
  "items": [
    {
      "id": 12,
      "course": { "id": 3, "code": "CS301", "name": "操作系统", "credits": 4, "dept": "计算机学院" },
      "term": "2026-FALL",
      "teacher": "李四",
      "capacity": 60,
      "enrolled_count": 58,
      "remaining": 2,
      "waitlist_count": 7,
      "meetings": [ { "weekday": 1, "start_period": 1, "end_period": 2 } ]
    }
  ],
  "total": 45, "page": 1, "size": 20
}
```

> `remaining` 与 `enrolled_count` 服务端计算；列表结果 Redis 缓存 5s（缓存 key 含全部查询参数）。

#### B2 GET /sections/{id}

响应 200：同 B1 单个对象，另加 `description`（课程简介）与 `batch`（所属选课批次）。

错误 404 `NOT_FOUND`。

### 5.3 选课/退课/我的

#### C1 POST /enrollments

请求：

```json
{ "section_id": 12, "allow_waitlist": true }
```

- `allow_waitlist` 默认 `true`。满员时：true→202 入队；false→409 `SECTION_FULL`。

处理顺序（与 01 文档第 7 章一致）：开放检查（423）→ 重复检查（409）→ 锁/原子更新（V1–V3）→ 冲突检测（409 `TIME_CONFLICT`）→ 成功或入队。

响应 201：

```json
{
  "status": "ENROLLED",
  "enrollment": {
    "id": 501,
    "section_id": 12,
    "course_name": "操作系统",
    "teacher": "李四",
    "meetings": [ { "weekday": 1, "start_period": 1, "end_period": 2 } ],
    "enrolled_at": "2026-11-19T10:30:00+08:00"
  }
}
```

响应 202：

```json
{
  "status": "WAITLISTED",
  "waitlist": { "id": 88, "section_id": 12, "position": 8, "joined_at": "2026-11-19T10:30:00+08:00" }
}
```

错误：409 `TIME_CONFLICT` 时：

```json
{ "error": { "code": "TIME_CONFLICT", "message": "与已选课程《数据结构》时间冲突",
  "details": { "conflicts": [ { "weekday": 1, "start_period": 1, "end_period": 2,
    "with_course_name": "数据结构" } ] } } }
```

#### C2 DELETE /enrollments/{id}

响应 204 无体。副作用：如该班有候选，队首自动晋升（同事务，见 01 文档 7.5）；晋升无条件成功时返回体不变，但前端"我的候选"列表下一次刷新即可见变化。

错误：404（不存在/非本人/已 DROPPED）；423（选课已关闭，禁止退课——按教务规则，退课与选课同开关）。

#### C3 GET /me/enrollments

响应 200：`{ "items": [ EnrolledSection ], "total": 8 }`，其中元素含 `enrollment_id`、`section_id`、`course`、`meetings`、`enrolled_at`。

#### C4 GET /me/waitlist

响应 200：

```json
{ "items": [ { "id": 88, "section_id": 12, "course_name": "操作系统",
  "position": 8, "section_enrolled": 60, "section_capacity": 60,
  "joined_at": "..." } ], "total": 2 }
```

#### C5 DELETE /waitlist/{id}

放弃候选：204。若该 entry 已被晋升（状态=ENROLLED），返回 409 `ALREADY_ENROLLED`（引导前端刷新“我的课程”）。

#### C6 GET /me/timetable

响应 200：

```json
{ "term": "2026-FALL",
  "cells": [ { "weekday":1, "start_period":1, "end_period":2,
    "course_name":"操作系统", "section_id":12, "color":"#4E79A7" } ] }
```

`color` 由服务端按 section_id 哈希生成，保证同一课程多端上色一致。

### 5.4 管理端

#### D1 GET /admin/courses

参数：`keyword`,`dept_id`,`archived`(默认 false)。响应分页 `items`：`{id,code,name,credits,dept,archived}`。

#### D2 POST /admin/courses

请求：`{ "code":"CS301","name":"操作系统","credits":4,"dept_id":1 }` → 201 返回对象。
错误：409 `DUPLICATE_RESOURCE`（code 重复）。

#### D3 PATCH /admin/courses/{id}

请求体同 D2 的可选字段 + `archived`。响应 200。

#### D4 GET /admin/sections

参数：`term`,`course_id`,`dept_id`,`page`,`size`。响应新增字段 `teacher`、`selection_open`。

#### D5 POST /admin/sections

请求：

```json
{ "course_id": 3, "term": "2026-FALL", "teacher": "李四",
  "capacity": 60,
  "meetings": [ { "weekday": 1, "start_period": 1, "end_period": 2 },
                { "weekday": 3, "start_period": 3, "end_period": 4 } ] }
```

校验：`capacity ≥ 1`；`meetings` 至少一段；同一 section 内部时间段不得重叠（400）。创建后 `enrolled_count=0`。
错误：409 `DUPLICATE_RESOURCE`（同课程同学期已有教学班）。

#### D6 PATCH /admin/sections/{id}

允许改 `capacity`（不得小于当前 enrolled_count，否则 409 `CAPACITY_BELOW_ENROLLED`）、`teacher`、`meetings`。

#### D7 GET /admin/sections/{id}/roster

参数：`page`,`size`。响应：

```json
{ "items": [ { "student_no":"S0001","name":"张三","enrolled_at":"...","source":"ENROLL|PROMOTED" } ],
  "total": 58 }
```

`source=PROMOTED` 表示由候选队列晋升而来（取 audit_log）。

#### D8 GET /admin/sections/{id}/roster.csv

`Content-Type: text/csv; charset=utf-8`，带 BOM（Excel 兼容），列：学号,姓名,选课时间,来源。文件名头 `Content-Disposition: attachment; filename="section_12_roster.csv"`。

#### D9 POST /admin/selection/open | /close

打开/关闭选课写阶段，响应 `{ "selection_open": true }`。关闭时进行中事务不受影响。

### 5.5 统计

#### E1 GET /stats/overview

```json
{ "total_enrollments": 1523, "open_sections": 45, "avg_utilization": 0.72,
  "waitlist_total": 88, "selection_open": true }
```

#### E2 GET /stats/hot-courses

参数 `limit`（默认 10）。响应 `{ "items":[ {"course_name":"操作系统","picks":120} ] }`。

#### E3 GET /stats/enrollment-series

参数 `term`、`hours`（默认 6）。响应：

```json
{ "points": [ { "ts": "2026-11-19T10:00:00+08:00", "count": 32 } ] }
```

实现：`audit_log` 按 5 分钟窗口聚合并起；前端画折线。

## 7. 接口变更流程

1. 修改本文档 + 相应 `schemas/`，在 PR 描述中写 `BREAKING: 是/否`；
2. 前端组 24 小时内评审 `BREAKING: 是` 的 PR；
3. 合并后更新前端 `src/api/` 中的类型定义（TS 类型由 OpenAPI 生成，脚本 `npm run gen:api`）。
